# Data Riwayat Pendidikan (Academic History Data)

Dokumen ini berisi data riwayat pendidikan yang siap disalin dan ditempel (copy-paste) ke formulir Pendidikan (Education form) pada website portofolio.

## Petunjuk Umum
- Gunakan blok kode di bawah ini untuk menyalin nilai secara cepat dan akurat.
- Unggah logo instansi ke direktori unggahan (misal: `/public/uploads/` atau folder sesuai konfigurasi website) menggunakan nama file yang disarankan pada kolom **LogoUrl**.
